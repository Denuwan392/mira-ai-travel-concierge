# Mira 2.0 Visual Reference Pack

This pack contains the user's four design inspiration screenshots and a detailed prompt for Codex.

1. Unzip into a **private/local** workspace alongside your existing Mira project. Copy `references/` to `<repo>/design/references/` if desired.
2. Copy the prompt markdown to the repository root.
3. In Codex, instruct it to read the markdown prompt and the reference images.
4. The images are for **design inspiration only**. Do not deploy these screenshots as user-facing website assets or claim rights to third-party designs.
5. The assignment brief and dataset remain private. Do not commit proprietary materials to a public repository.
