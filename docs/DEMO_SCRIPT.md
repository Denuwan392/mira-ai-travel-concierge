## 2. Live Technical Interview Preparation Checklist

### A. Three-Minute Architecture Pitch
1. **Separation of Concerns:** Client presentation (TanStack Start React) $\leftrightarrow$ A2UI Protocol $\leftrightarrow$ Orchestration (LangGraph on FastAPI) $\leftrightarrow$ Deterministic Engine (Python Decimal).
2. **Deterministic Pricing Guarantee:** Zero LLM math. All rates, margins, deposits, and single supplements are derived from Excel rate sheets via Decimal arithmetic.
3. **Structured UI Constraints:** Pydantic `Strict(BaseModel)` with `extra="forbid"`. The LLM cannot emit arbitrary HTML, scripts, or unapproved components.
4. **Resilient Governance:** Append-only audit triggers, role-gated publication, and isolated traveler sessions.

### D. Common Technical Questions & Grounded Answers

**Q1: Why did you use LangGraph instead of a standard LangChain agent or AutoGen?**  
> *"LangGraph provides explicit, auditable control over state transitions and conditional branching. In a travel booking system, we cannot permit an autonomous agent loop to decide arbitrarily when to query pricing or complete a transaction. LangGraph's directed cyclic graph lets us enforce strict deterministic gates: `interpret` $\to$ `retrieve` $\to$ `quote_route` (conditional) $\to$ `quote` $\to$ `compose` $\to$ `save`. Furthermore, its state schema is strongly typed and integrates directly with the AG-UI protocol adapter."*

**Q2: Why not let Gemini calculate discounts or quote prices directly?**  
> *"Large language models are probabilistic token predictors, not arithmetic engines. In financial travel contracts, an error of a few dollars or an invented discount can cause direct balance-sheet losses or regulatory breach. By keeping pricing strictly in Python Decimal code, we guarantee mathematical consistency, fixed FX conversions, strict group boundaries, and 100% adherence to hotel contract terms."*

**Q3: How does the system handle concurrent users and data race conditions?**  
> *"We use SQLite in WAL mode with `BEGIN IMMEDIATE` transaction isolation on all state-modifying endpoints (`persist`, `booking`, `follow_up`). Furthermore, each trip entity enforces optimistic concurrency control using a monotonic `revision` counter: if two concurrent requests attempt to mutate the same trip, the revision mismatch raises an immediate conflict error."*

**Q4: How do you prevent sensitive traveler data from leaking into Langfuse or console logs?**  
> *"All logging and tracing flows through `observability.py`. We maintain an allowlist of metadata keys and inspect all attributes for sensitive substrings (`token`, `secret`, `bearer`, `auth`, `cost_lkr`, `private`). Any string values containing email addresses or authorization headers are regex-masked (`[REDACTED_EMAIL]`, `Bearer [REDACTED]`). Internal buy costs are stored in private columns for staff audits and excluded from public traces."*
