## Status Legend
- **VERIFIED:** Implemented in code, backed by automated tests, and verified via runtime execution.
- **IMPLEMENTED BUT UNVERIFIED:** Implemented in code, but automated tests or runtime verification are incomplete or absent.
- **PARTIAL:** Some parts of the requirement are implemented; critical aspects remain incomplete.
- **MISSING:** Not implemented in source code.
- **BLOCKED:** Cannot be executed or verified due to external environment restrictions.
